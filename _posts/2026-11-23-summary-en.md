**「Background」** Lean is an open-source programming language and proof assistant designed for writing formally verified code. Recent discussions have centered on the feasibility and implications of generating large volumes of Lean code using LLMs, such as the recent generation of 17 million lines of code. While Lean has been used in verified software projects, the scale and readability of AI-generated code raises new concerns about maintainability and reviewability.

**「Impact」** The generation of 17 million lines of Lean code using LLMs highlights growing concerns about the practicality and trustworthiness of AI-assisted formal verification, as the sheer volume of code makes human review infeasible and increases the risk of hidden flaws going undetected.

**「Community Discussion」** Some commenters noted that LLM-generated code often lacks human readability, as models struggle to contextualize information for audiences unfamiliar with the underlying problem or solution. Others expressed unease about the inability to fully review such massive volumes of code, raising concerns about potential hidden flaws or malicious content.
